# Provenance

- `malicious_phish.csv`: local Kaggle-style snapshot supplied with the project; source licence is not embedded in the file, so it is treated as provenance-uncertain and used for development only.
- PhreshPhish, academic sets, Common Crawl, Tranco, OpenPhish, PhishTank: not included in this offline rebuild; no credentials or network fetches were used.

URLs are strings only. The pipeline never resolves, crawls, or downloads URL content.
